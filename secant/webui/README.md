# Secant WebUI

Planned Phase 1 contents:

- Privileged `secant://` WebUI scheme.
- Vertical tab strip, sidebar and workspace switcher surfaces.
- Strict CSP, local assets and no remote scripts.
- Narrow Mojo API for tab, workspace and window actions.
- Input latency, focus, IME and accessibility harnesses.

This directory is a skeleton until the WebUI host and Mojo interface are added.
